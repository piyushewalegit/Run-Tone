# Change Log

All notable changes to the RunTone extension will be documented in this file.

## [0.0.1] - 2026-10-05

### Added

- 🔊 Success sound when code execution succeeds
- ❌ Error sound when code execution fails
- 🎵 Custom `.wav` sounds for success and error
- 🔘 Enable/disable RunTone
- ⏱️ Maximum 5-second sound playback
- 🌍 Support for multiple programming languages
- 🚫 Ignores unrelated terminal commands
- 🖼️ RunTone Marketplace icon
